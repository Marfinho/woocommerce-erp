# Harmonisierte Mitteilung zur gesetzlichen Gewährleistung

- `gewaehrleistung-eu-de.png` / `gewaehrleistung-eu-de.pdf`: deutsche Fassung der
  harmonisierten Mitteilung nach der Durchführungsverordnung (EU) 2025/1960
  (zur Richtlinie (EU) 2024/825), Pflicht ab 27. September 2026.
- Quelle: Vorlage der EU-Kommission, unverändert übernommen aus dem Plugin
  Germanized (`assets/images/legal-guarantee/legal_guarantee_notice-de.png`
  und `pdf/legal_guarantee_notice-de.pdf`).
- Die Mitteilung darf nicht verändert, verzerrt oder beschnitten werden. Das
  Theme zeigt sie deshalb ohne Rundung und ohne Zuschnitt
  (Pattern `lindenweg16/hidden-legal-guarantee`, auf jeder Produktseite).
