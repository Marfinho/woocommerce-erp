# Block-Theme „Lindenweg16“

Installierbares WordPress-Block-Theme (Full Site Editing) für den
WooCommerce-Shop von Lindenweg16 mit dem Haster Haken.

- Theme-Quellen: `lindenweg16/`
- Fertiges ZIP zum Hochladen: `dist/lindenweg16.zip`
  (Design → Themes → Theme hinzufügen → Theme hochladen)
- Anleitung, Farben, Block-Styles, Patterns: `lindenweg16/readme.txt`

Neu bauen und prüfen:

```bash
bash block-theme/build-zip.sh
python3 block-theme/check-theme.py            # optional: Pfad zum theme.json-Schema als Argument
```

Das klassische Theme in `theme/` ist davon unabhängig und bleibt unverändert.
