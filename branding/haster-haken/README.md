# Haster Haken – Logo (Entwurf, Richtung 2 „Gestapelte Ordnung“)

Abstrakte Bildmarke: eine Achse (Schiene) in Schiefer, daran drei gleiche
Module in Eichenhonig, versetzt – das Baukastenprinzip „Set oder einzeln“.
Schriftzug in Bricolage Grotesque ExtraBold (wie die Website), in Kurven.

## Website

Das Theme bringt das Logo als Inline-SVG mit (inc/haster-logo.php) – animiert,
in den Palettenfarben. Auf der Startseite steht die Marke neben „Handgemacht in
Haste“; das Muster „Haster-Haken-Logo (animiert)“ lässt sich auf jeder Seite
einfügen.
